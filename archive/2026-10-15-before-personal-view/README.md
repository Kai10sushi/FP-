# 制度の翻訳室（仮）
更新日：2026-09-12

さまざまな制度を、視聴者が「自分にどう関係するか」「どんな場面で役立つか」「次に何を確認すればよいか」まで理解できるように解説する動画チャンネルです。社会保険は最初のシリーズであり、チャンネル全体の対象分野を限定しません。

## 目的と運営条件

- 調査・説明・振り返りを通じ、自分の制度知識と説明力を高め、本業の会話にも役立てる。
- 継続的なYouTube発信で収益化を目指す。中長期の収益化目標は維持するが、達成を保証するものではない。
- 本業を維持し、土日中心・隔週1本で制作する。初期予算は1万円以内。
- 通常動画8〜12分、初回の全体像は8〜10分を目安とし、説明に必要な長さを優先する。
- 勤務先の許可は未確認。公開前に副業・SNS発信の規程を確認する。

## 根拠と公開責任

公式情報の記録は source-log.md と research/source-packet-template.md、勤務先・発信上の確認は compliance-checklist.md、レビューは reviews/review-receipt-template.md を使います。資料にあるURLも公開前に再確認します。AI出力やSNS投稿だけを制度の根拠にしません。

AIは整理・初稿・レビューを補助します。公開承認と実際の投稿は人間が行い、今回の更新ではチャンネル開設・投稿・自動化設定は行っていません。AI担当の運用は ai-company-operating-model.md、ai-company-role-matrix.md、ai-company-workflow.md を参照します。
