# 制度解説動画テンプレート

## 企画メモ

- 仮タイトル：
- 誰の疑問に答えるか：
- 視聴者が見終わったあとにできること：
- 制度の一言結論：
- 今回扱わない範囲：
- 想定尺：60〜90秒

## 台本

### 1. フック（0〜3秒）

「＿＿＿のとき、＿＿＿はどうなる？」

### 2. 結論（3〜15秒）

「結論から言うと、＿＿＿という制度があります。ただし、＿＿＿が条件です。」

### 3. 要点（15〜55秒）

- 対象：
- 対象外・注意：
- 年齢、所得、期間、加入先などの条件：

### 4. 次の行動（55〜75秒）

「まずは＿＿＿の公式ページ／窓口で、＿＿＿を確認してください。」

### 5. 注意書き（75〜90秒）

「これは一般的な概要です。条件や金額は個別に異なるため、最新の公式情報と専門窓口をご確認ください。」

## 公開前の事実確認

- [ ] 省庁、自治体、保険者、運営主体などの一次情報源を確認した
- [ ] 情報源のURL、ページ名、確認日を記録した
- [ ] 制度の対象者・対象外を確認した
- [ ] 金額、割合、期限、年齢、所得区分を確認した
- [ ] 適用開始日・改正日・経過措置を確認した
- [ ] 「原則」「場合がある」「例外」などの条件を省略していない
- [ ] 実例が制度上の一般例であることを明示した
- [ ] 個別の加入・投資・節税・保険契約を勧める表現になっていない
- [ ] 勤務先、顧客、見込み客の秘密情報を使っていない
- [ ] 投稿後に制度が変わった場合の更新方法を決めた

## AIを使った場合の確認

- [ ] AIの回答を出典として扱っていない
- [ ] AIが作った数字・固有名詞・リンクを公式資料で再確認した
- [ ] 台本にない余計な断定を撮影中に加えていない
