# 制度の翻訳室（仮）

働く人が「知らないまま損をする」ことを減らすために、公的保障とお金の制度を、短い動画でわかりやすく解説する副業プロジェクトです。

## プロジェクトの目的

- 本業の安定を保ちながら、自由な働き方につながる収入源を育てる
- 継続的な発信と収益化を目指す
- 土日中心・初期費用1万円以内で小さく始める
- 保険営業、FP2級、簿記3級、説明力・分析力を組み合わせて、自分の知識と市場理解も伸ばす

## 仮のポジション

> 働く人向けに、公的保障とお金の制度を60〜90秒で「自分に関係ある話」へ翻訳するチャンネル。

最初から「高額療養費、iDeCo、法人税」を同じ比重で扱うと視聴者像がぼやけるため、最初の30本程度は「会社員の公的保障」を主軸にします。iDeCoは第2段階、法人税は会社員・経営者向けの別シリーズとして反応を見ながら追加します。

## 想定する視聴者

主な対象は、制度の名前は聞いたことがあるものの、病気・休職・老後・家計の場面で何を確認すればよいかわからない会社員です。

副次的な対象として、営業社員、若手社員、家族のお金を考え始めた人を想定します。中小企業経営者への専門コンサルティングは、知識と実績を蓄積してから検討します。

## 段階的なテーマ設計

### 第1段階：会社員の公的保障

高額療養費制度、傷病手当金、障害年金、遺族年金、出産・育児の給付、雇用保険など。

### 第2段階：資産形成と老後

iDeCo、NISA、公的年金、退職金、家計の制度。制度の概要と確認先を扱い、個別商品の推奨はしません。

### 第3段階：法人・事業のお金

法人税、消費税、役員報酬、社会保険など。法人税は「法人の利益にかかる税金」という基礎から始め、個別の節税判断や申告代行には踏み込みません。

## 収益化の仮説

1. 無料動画で、説明力・制度理解・視聴者の悩みを蓄積する
2. 反応のよいテーマを、資料付きの少人数勉強会や一般向け講座にする
3. 将来的に、営業社員向けの公的保障・お金の制度研修や、企業の従業員向け金融リテラシー研修を検討する
4. 収益化の前に、勤務先の副業規程、保険募集に関する社内ルール、資格・税務・金融関連の境界を確認する

最初の90日間は、売上よりも「継続可能な制作方法」「視聴者が保存・質問したくなるテーマ」「自分が説明できる範囲」を検証します。

## 最初の90日間の成果目標

- 30日で8本以上を公開する
- すべての動画に一次情報源と確認日を付ける
- 1本あたりの企画・調査・撮影・編集時間を記録する
- 保存数、最後まで見られた割合、コメント・質問を記録する
- 30本まではテーマを広げすぎず、上位3テーマを特定する

## AI会社型の運営方針

このチャンネルは「AIが勝手に運営する会社」ではなく、「人間オーナーが責任を持ち、AIが狭い役割を分担する小さな編集会社」として運用します。

```text
X・コメントの信号
  → 企画ブリーフ
  → 公式情報パケット／主張台帳
  → 事実レビュー
  → 台本初稿
  → 品質・コンプライアンスレビュー
  → 人間オーナー承認
  → 人間が公開
  → 計測・実験ログ
```

AIは調査整理、初稿、分類、集計までを担当できますが、公式情報の正本化、公開承認、X上の投稿・返信・DM・フォロー、個別の保険・金融・税務判断は行いません。Xは制度の根拠ではなく、視聴者の疑問を見つける信号として扱います。

## Dラボから取り入れる原則

このプロジェクトは、Dラボで扱われている「付加価値」「副業の探索と実験」「信頼構築」「長期戦」の考え方を実行用に落とし込みます。

- 広い知識を並べるのではなく、「働く人の制度を翻訳する」という対象と困りごとを絞る
- いきなり講座や商品を作らず、短い動画を小さな実験として出す
- 反応がよいテーマと、自分が無理なく説明できるテーマの交差点を探す
- AIは調査整理・台本のたたき台・改善分析に使い、最終確認と責任は自分が持つ
- 継続できる頻度と制作工程を先に作り、反応を見てから収益化する
