## 目的と運営条件

- 調査・説明・振り返りを通じ、自分の制度知識と説明力を高め、本業の会話にも役立てる。
- 継続的なYouTube発信で収益化を目指す。中長期の収益化目標は維持するが、達成を保証するものではない。
- 本業を維持し、土日中心・隔週1本で制作する。初期予算は1万円以内。
- 通常動画8〜12分、初回8〜10分は従来の目安。今回の初回v7は仮7分5秒へ短縮し、説明に必要な長さを優先する。
- 勤務先の許可は未確認。公開前に副業・SNS発信の規程を確認する。
