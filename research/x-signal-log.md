# Xシグナルログ

Xはテーマ発見にだけ使い、制度の事実の根拠にはしない。公開投稿を一般化した疑問として記録し、必ず公式ページへ戻って検証する。

## 記録ルール

- 投稿URL、アカウント、公開日、確認日を記録する
- 氏名・勤務先・病気・所得・家族状況などの個人情報を収集しない
- 投稿を転載・晒し・営業対象にしない
- 閲覧数・いいね数・フォロワー数を需要の証明にしない
- 無断スクレイピング、無差別収集、自動投稿、返信、DM、フォローをしない

## 記録テンプレート

```markdown
## SIG-YYYYMMDD-NN

- 確認日：
- 投稿URL：
- アカウント表示名：
- 投稿の公開日：
- シグナル種別：制度名の混乱 / 生活場面の不安 / 改正への疑問 / 申請先の疑問 / 表現・タイトル / その他
- 投稿から一般化した疑問：
- 検証する公式情報源：
- 確認した公式URL：
- 台本へ採用する論点：
- 採用しない理由・リスク：
- 関連案件ID：
- 次の担当：
```
